# RHWP Studio 설치 안내 (직원용)

RHWP Studio는 한/글(HWP·HWPX) 문서를 여닫고 편집할 수 있는 사내 배포용 프로그램입니다. 아래 순서대로
설치하세요.

## 1. 설치 파일 다운로드

사내 포털([portal.kdsys.co.kr](https://portal.kdsys.co.kr))의 **업무도구** 컬럼에서
사용 중인 PC에 맞는 카드를 클릭하면 최신 설치 파일이 바로 다운로드됩니다.

- **RHWP Studio 설치 (Windows)** — `RHWP Studio_<버전>_x64-setup.exe`
- **RHWP Studio 설치 (macOS)** — `RHWP Studio_<버전>_universal.dmg`
  (Apple Silicon·인텔 맥 공용)

> macOS에서 처음 실행할 때 "확인되지 않은 개발자" 안내가 나오면, 응용 프로그램
> 폴더에서 앱을 **마우스 오른쪽 클릭 → 열기**로 한 번만 실행해 주세요.

설치 후에는 프로그램이 스스로 새 버전을 확인해 업데이트하므로 다시 내려받을 필요가
없습니다(아래 [자동 업데이트](#6-자동-업데이트) 참고).

## 2. 실행

다운로드한 `.exe` 파일을 더블클릭합니다.

이때 **"Windows에서 PC를 보호했습니다"** 라는 파란 화면이 나타날 수 있습니다. 이 프로그램은 사내에서
직접 배포하는 프로그램이라 발생하는 정상적인 안내이며, 아래와 같이 진행하면 됩니다.

1. 화면의 **"추가 정보"** 를 클릭합니다.
2. 나타나는 **"실행"** 버튼을 클릭합니다.

## 3. 설치 마법사 진행

화면 안내에 따라 "다음"을 눌러 설치를 완료합니다. 설치 중 관리자 권한 확인(UAC) 창이 뜨면 "예"를
눌러주세요 — 프로그램을 신뢰할 수 있는 프로그램으로 등록하는 과정입니다.

## 4. 실행 확인

설치가 끝나면 시작 메뉴에서 **RHWP Studio**를 검색해 실행할 수 있습니다.

## 5. .hwp / .hwpx 파일을 기본적으로 RHWP Studio로 열기 (선택)

설치 후에도 탐색기에서 `.hwp`/`.hwpx` 파일을 더블클릭하면 기존에 쓰던 프로그램이 계속 열릴 수
있습니다. RHWP Studio로 바로 열리게 하려면:

1. 해당 파일을 마우스 오른쪽 버튼으로 클릭
2. **"다른 프로그램으로 열기"** 선택
3. **RHWP Studio** 선택
4. **"항상 이 앱을 사용하여 .hwp/.hwpx 파일 열기"** 체크

이 설정은 강제로 바뀌지 않으므로, 기존 프로그램을 계속 기본으로 쓰고 싶다면 위 과정을 건너뛰어도
됩니다.

## 6. 자동 업데이트

RHWP Studio는 실행할 때마다 사내 포털에서 새 버전이 있는지 조용히 확인합니다.
새 버전이 있으면 설치 여부를 묻는 창이 뜨고, "확인"을 누르면 내려받아 설치한 뒤
자동으로 다시 시작됩니다.

지금 바로 확인하고 싶다면 **파일 메뉴 → 업데이트 확인**을 누르세요. 이미 최신이면
"이미 최신 버전을 사용 중입니다"라고 알려줍니다.

> 업데이트 확인은 사내 포털(portal.kdsys.co.kr)에 연결될 때만 동작합니다. 사외망에서
> 확인에 실패해도 프로그램 사용에는 지장이 없습니다.

## 문의

설치나 사용 중 문제가 있으면 문의해 주세요.
