# RHWP Studio 설치 안내 (직원용)

RHWP Studio는 한/글(HWP·HWPX) 문서를 여닫고 편집할 수 있는 사내 배포용 프로그램입니다. 아래 순서대로
설치하세요.

## 1. 설치 파일 다운로드

담당 부서(IT팀)에서 공유한 `rhwp-studio-setup-v<버전>.exe` 파일을 다운로드합니다.

## 2. 실행

다운로드한 `.exe` 파일을 더블클릭합니다.

이때 **"Windows에서 PC를 보호했습니다"** 라는 파란 화면이 나타날 수 있습니다. 이 프로그램은 사내에서
직접 배포하는 프로그램이라 발생하는 정상적인 안내이며, 아래와 같이 진행하면 됩니다.

1. 화면의 **"추가 정보"** 를 클릭합니다.
2. 나타나는 **"실행"** 버튼을 클릭합니다.

## 3. 설치 마법사 진행

화면 안내에 따라 "다음"을 눌러 설치를 완료합니다. 설치 중 관리자 권한 확인(UAC) 창이 뜨면 "예"를
눌러주세요 — 프로그램을 신뢰할 수 있는 프로그램으로 등록하는 과정입니다.

## 4. 실행 확인

설치가 끝나면 시작 메뉴에서 **RHWP Studio**를 검색해 실행할 수 있습니다.

## 5. .hwp / .hwpx 파일을 기본적으로 RHWP Studio로 열기 (선택)

설치만으로는 기존 연결이 바뀌지 않습니다. 탐색기에서 `.hwp`/`.hwpx` 파일을 더블클릭했을 때
RHWP Studio로 열리게 하려면 앱에서 켜 주세요.

1. RHWP Studio 실행
2. **도구 > 환경 설정**
3. **파일 연결** 항목의 **".hwp / .hwpx 파일을 RHWP Studio로 열기"** 체크
4. **확인**

나중에 같은 자리에서 체크를 해제하면 원래 쓰던 프로그램으로 되돌아갑니다. 이 설정은 지금
로그인한 사용자에게만 적용되며, 관리자 권한이 필요하지 않습니다.

## 6. 문제가 생겼을 때 (진단 로그)

앱이 예상과 다르게 동작하면 진단 로그를 함께 보내 주시면 원인 파악이 훨씬 빨라집니다.

1. **도구 > 진단 로그 폴더 열기**
2. 열린 폴더에서 **가장 최근 파일**을 문의에 첨부

폴더가 열리지 않으면 경로가 안내창에 표시되고 클립보드에 복사됩니다. 로그에는 문서 내용이
기록되지 않습니다 — 앱 버전, 오류 메시지, 문서의 형식·크기·쪽수 같은 정보만 남습니다.

## 문의

설치나 사용 중 문제가 있으면 문의해 주세요.
